# RZ — Site vitrine

Site vitrine officiel de **Rasolomanantsoa Zafiarijaona (RZ)**, une entreprise spécialisée dans le **bâtiment et les travaux publics (BTP)**.

Le site présente l'entreprise, ses activités, son personnel, ses projets et ses actualités, ainsi que ses informations de contact.

## 🌐 Site en ligne

Le site est déployé sur **Netlify** et accessible via un **nom de domaine personnalisé** acheté pour l'entreprise.

lien du site : rasolomanantsoa.mg

## ✨ Fonctionnalités

- 🏠 Présentation de l'entreprise
- 👷 Présentation du personnel
- 🏗️ Présentation des activités
- 📁 Présentation des projets réalisés
- 📰 Section actualités
- 📞 Informations et moyens de contact
- 📱 Design responsive adapté aux ordinateurs, tablettes et smartphones
- ✨ Animations et effets visuels
- 📊 Compteurs et éléments interactifs

## 🛠️ Technologies utilisées

- **HTML5** — Structure des pages
- **CSS3** — Mise en page, responsive design et animations
- **JavaScript** — Interactions et fonctionnalités dynamiques
- **SVG** — Icônes et éléments graphiques

Aucun framework frontend n'est utilisé : le site repose sur du **HTML, CSS et JavaScript vanilla**.

## 🚀 Déploiement

Le projet est déployé avec **Netlify**.

Le déploiement est connecté au dépôt GitHub afin de faciliter la mise en ligne des nouvelles versions du site.

### Domaine

Le site utilise un **nom de domaine personnalisé**, acheté séparément puis configuré pour pointer vers le déploiement Netlify.

## 💻 Installation en local

Aucune installation particulière n'est nécessaire.

Cloner le dépôt :

```bash
git clone https://github.com/Tsiiva/rasolomanantsoa-website.git
```

Puis ouvrir le fichier `index.html` dans un navigateur.

Pour une meilleure expérience de développement, il est également possible d'utiliser une extension comme **Live Server** avec Visual Studio Code.

## 📱 Compatibilité

Le site est conçu pour fonctionner sur :

- 💻 Ordinateurs
- 📱 Smartphones
- 📲 Tablettes

Les principaux navigateurs modernes sont supportés.

## 🎯 Objectif du projet

L'objectif de ce projet est de créer une présence web professionnelle pour l'entreprise RZ afin de :

- présenter son activité ;
- mettre en avant ses réalisations ;
- présenter son équipe ;
- faciliter la prise de contact ;
- renforcer sa présence en ligne.
